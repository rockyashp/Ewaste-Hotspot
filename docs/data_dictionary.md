# Data Dictionary: E-Waste Hotspot & Collection Planner

## 1. Overview
This document defines every variable, field type, measurement unit, derivation formula, and provenance source across the datasets used and generated by the system.

---

## 2. Master Planning Dataset (`data/processed/mumbai_final_planning_matrix.csv` / `.geojson`)

| Field Name | Type | Unit / Format | Provenance / Category | Description |
| :--- | :--- | :--- | :--- | :--- |
| `name` | String | e.g., 'K/W', 'A' | `ACTUAL DATA` | Official BMC Administrative Ward code (24 wards: A through T). |
| `ward_full_name` | String | Text | `ACTUAL DATA` | Full locality names encompassed by the ward (e.g., 'Andheri West / Versova / Juhu'). |
| `gid` | Integer | ID | `ACTUAL DATA` | Internal geographic polygon ID from `BMC_Wards.geojson`. |
| `total_population` | Integer | Persons | `ACTUAL DATA` | Census 2011 population aggregated from 97 Census sub-wards. |
| `male_population` | Integer | Persons | `ACTUAL DATA` | Census 2011 male population count. |
| `female_population` | Integer | Persons | `ACTUAL DATA` | Census 2011 female population count. |
| `area_sqkm` | Float | km² | `DERIVED DATA` | Precise land area calculated from polygon geometry in projected CRS EPSG:32643 (UTM 43N). |
| `perimeter_km` | Float | km | `DERIVED DATA` | Perimeter of ward polygon calculated in projected CRS. |
| `centroid_lat` | Float | Degrees North | `DERIVED DATA` | Geographic centroid latitude (WGS84). |
| `centroid_lon` | Float | Degrees East | `DERIVED DATA` | Geographic centroid longitude (WGS84). |
| `pop_density_per_sqkm`| Float | persons/km² | `DERIVED DATA` | Census 2011 population density (`total_population / area_sqkm`). |
| `pop_growth_rate_annual`| Float | Fraction | `ESTIMATED DATA` | Differentiated annual CAGR based on BMC Development Plan 2034 (Island: 0.25%, Western: 0.95%, Eastern: 0.85%). |
| `pop_2024_projected` | Integer | Persons | `ESTIMATED DATA` | Projected 2024 population applying 13-year compounding: $\text{Pop}_{2011} \times (1 + r)^{13}$. |
| `pct_radio` | Float | % Households | `ACTUAL DATA` | % Households with Radio/Transistor (Census Table HH-14, population-weighted). |
| `pct_tv` | Float | % Households | `ACTUAL DATA` | % Households with Television (Census Table HH-14, population-weighted). |
| `pct_pc_internet` | Float | % Households | `ACTUAL DATA` | % Households with Computer/Laptop with Internet (Census Table HH-14). |
| `pct_pc_no_internet` | Float | % Households | `ACTUAL DATA` | % Households with Computer/Laptop without Internet (Census Table HH-14). |
| `pct_total_pc` | Float | % Households | `DERIVED DATA` | Composite computer ownership: `pct_pc_internet + pct_pc_no_internet`. |
| `pct_landline_only` | Float | % Households | `ACTUAL DATA` | % Households with Landline telephone only (Census Table HH-14). |
| `pct_mobile_only` | Float | % Households | `ACTUAL DATA` | % Households with Mobile phone only (Census Table HH-14). |
| `pct_total_phone` | Float | % Households | `DERIVED DATA` | Total telephone penetration (`pct_landline_only + pct_mobile_only`). |
| `pct_high_asset` | Float | % Households | `ACTUAL DATA` | % Households owning TV, Computer, Phone, and Vehicle simultaneously (High asset affluence). |
| `pct_no_asset` | Float | % Households | `ACTUAL DATA` | % Households owning none of the specified assets (Deprivation index). |
| `commercial_electronics_poi_count` | Integer | Count | `ACTUAL DATA` | Number of verified electronics retail, repair, and recycling points mapped from OpenStreetMap. |
| `commercial_electronics_density` | Float | POIs/km² | `DERIVED DATA` | Spatial commercial intensity (`commercial_electronics_poi_count / area_sqkm`). |
| `eaf_asset_factor` | Float | Ratio | `DERIVED DATA` | Multi-device electronic affluence factor normalized relative to municipal mean. |
| `caf_commercial_factor` | Float | Multiplier (1.0 - 1.3)| `DERIVED DATA` | Commercial activity multiplier scaling institutional turnover. |
| `ewaste_gen_annual_mt_baseline` | Float | Metric Tonnes/yr | `ESTIMATED DATA` | Baseline estimated annual e-waste generation calibrated against CPCB/MPCB benchmarks. |
| `ewaste_gen_annual_mt_low` | Float | Metric Tonnes/yr | `ESTIMATED DATA` | Conservative lower-bound estimate (89.5k MT citywide target). |
| `ewaste_gen_annual_mt_high` | Float | Metric Tonnes/yr | `ESTIMATED DATA` | Upper-bound accelerated consumption estimate (125.5k MT citywide target). |
| `ewaste_per_capita_kg_year` | Float | kg/person/yr | `DERIVED DATA` | Estimated annual per-capita e-waste generation (`gen_mt * 1000 / pop_2024`). |
| `ewaste_gen_daily_mt` | Float | Metric Tonnes/day | `DERIVED DATA` | Estimated daily generation rate (`gen_mt / 365`). |
| `ewaste_density_mt_per_sqkm` | Float | MT/km²/yr | `DERIVED DATA` | Spatial concentration of generation (`gen_mt / area_sqkm`). |
| `score_volume_component` | Float | 0 - 100 | `DERIVED DATA` | Normalized score for absolute volume dimension. |
| `score_density_component` | Float | 0 - 100 | `DERIVED DATA` | Normalized score for spatial generation density dimension. |
| `score_affluence_component` | Float | 0 - 100 | `DERIVED DATA` | Normalized score for household asset affluence dimension. |
| `score_commercial_component` | Float | 0 - 100 | `DERIVED DATA` | Normalized score for commercial IT/electronics density dimension. |
| `hotspot_index_cehi` | Float | 0 - 100 | `MODEL PREDICTION`| Composite E-Waste Hotspot Index combining the 4 normalized dimensions. |
| `hotspot_category` | Category | 'HIGH'/'MEDIUM'/'LOW'| `MODEL PREDICTION`| Policy classification tier: HIGH ($\ge 60$), MEDIUM ($35 - 60$), LOW ($< 35$). |
| `cluster_id` | Integer | 0 to 3 | `MODEL PREDICTION`| Cluster assigned by K-Means unsupervised machine learning ($k=4$). |
| `cluster_archetype` | String | Typology Name | `MODEL PREDICTION`| Named ward archetype based on cluster centroid features. |
| `primary_hotspot_driver` | String | Text | `MODEL PREDICTION`| Dimension contributing highest relative weight to ward's hotspot score. |
| `explainability_text` | String | Narrative | `MODEL PREDICTION`| Auditable natural-language narrative answering "Why is this ward a hotspot?". |
| `nearest_facility_name` | String | Name | `ACTUAL DATA` | Name of the closest licensed MPCB e-waste recycler/refurbisher. |
| `nearest_facility_distance_km` | Float | Kilometers | `DERIVED DATA` | Haversine distance from ward centroid to nearest facility. |
| `nearest_facility_type` | String | 'Recycler'/'Refurbisher'| `ACTUAL DATA` | Operational type of the closest authorized facility. |
| `nearest_facility_capacity_mta`| Float | MT/annum | `ACTUAL DATA` | Permitted annual processing capacity allotted under MPCB Consent to Operate. |
| `nearest_facility_ro` | String | e.g. 'Thane', 'Mumbai' | `ACTUAL DATA` | MPCB Regional Office jurisdiction. |
| `facilities_within_10km` | Integer | Count | `DERIVED DATA` | Total licensed facilities accessible within a 10 km straight-line radius. |
| `accessible_capacity_15km_mta` | Float | MT/annum | `DERIVED DATA` | Aggregate licensed recycling capacity within a 15 km service corridor. |
| `infrastructure_access_score_ias`| Float | 0 - 100 | `DERIVED DATA` | Composite accessibility score based on distance, count, and capacity. |
| `infrastructure_gap_index_igi` | Float | 0 - 100 | `MODEL PREDICTION`| Infrastructure Gap Index: $\text{Norm}(CEHI) \times (1 - \text{Norm}(IAS))$. |
| `collection_gap_status` | Category | 'CRITICAL'/'MODERATE'/'WELL SERVED' | `MODEL PREDICTION`| Policy classification of collection coverage gap. |
| `estimated_unserved_volume_mt` | Float | MT/year | `ESTIMATED DATA` | Volume at risk of diversion into informal/uncontrolled scrap channels. |
| `recommended_strategy` | String | Policy Title | `MODEL PREDICTION`| Actionable municipal collection intervention assigned via Decision Engine. |
| `recommended_frequency` | String | Operational Cadence | `MODEL PREDICTION`| Recommended pickup frequency for the ward. |
| `weekly_collection_trips_needed`| Integer | Trips/week | `ESTIMATED DATA` | Required weekly municipal truck/van trips assuming 2.5 MT vehicle capacity. |
| `municipal_priority_tier` | String | Priority Class | `MODEL PREDICTION`| Municipal budgetary and operational priority classification. |
| `recommendation_rationale` | String | Narrative | `MODEL PREDICTION`| Auditable explanation justifying why this collection strategy was assigned. |

## 3. MPCB Authorized Facilities Dataset (`data/processed/mpcb_authorized_facilities.csv`)

| Field Name | Type | Unit | Description |
| :--- | :--- | :--- | :--- |
| `sr_no` | Integer | ID | Regulatory serial number in official MPCB registry. |
| `facility_name` | String | Name | Registered legal entity name of the recycler/refurbisher. |
| `regional_office` | String | Jurisdiction | MPCB Regional Office (e.g., Mumbai, Thane, Kalyan, Raigad, Pune). |
| `facility_type` | String | Type | Permitted activity ('Recycler', 'Refurbisher', 'Dismantler'). |
| `capacity_mta` | Float | MT/A | Permitted annual processing capacity in Metric Tonnes per Annum. |
| `contact_email` | String | Email | Official regulatory contact email. |
| `contact_phone` | String | Phone | Contact phone number. |
| `latitude` | Float | Degrees N | Geocoded latitude coordinate. |
| `longitude` | Float | Degrees E | Geocoded longitude coordinate. |
| `serves_mmr` | Boolean | True/False | Indicates if facility is within 120 km transport corridor of Mumbai. |
| `full_address` | String | Address | Full industrial estate address as stated in Consent to Operate. |
